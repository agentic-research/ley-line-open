Section: Breaking
- **Wire break: `query` rows are positional arrays, not objects keyed by column name** (bead `ley-line-open-0a18bc`). A keyed row lost a value whenever two columns shared a name: `SELECT 1 AS id, 2 AS id` answered `[{"id": "2"}]`. Each row is now an array in `columns` order, so that query answers `[["1", "2"]]`; SQL NULL is JSON `null`, distinct from `""`, and values keep their text rendering. `columns`, `truncated` and `limit` are unchanged. A client that reads `row[column_name]` must read `row[i]` for the column's index. In `daemon.capnp`, `QueryResponse.rows` is a new field (@5, `List(List(Text))`); the old @2 is retired as `rowsV0` and never emitted. The Go mirror's `wire.QueryResponse.Rows` is `[][]*string`, and `wire.QueryRow` is removed. The Go drift gate no longer skips `query`.
