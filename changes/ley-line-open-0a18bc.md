Section: Breaking
- **Wire break, `wire_format_major` 3: `query` rows are lists of typed cells in `columns` order, not objects keyed by column name** (bead `ley-line-open-0a18bc`). A keyed row lost a value whenever two columns shared a name: `SELECT 1 AS id, 2 AS id` answered `[{"id": "2"}]`. Each row is now a list of `QueryCell` unions, one per column in `columns` order, so that query answers `[[{"text": "1"}, {"text": "2"}]]`. A cell is `{"null": null}` for SQL NULL or `{"text": "..."}` for every other value, so NULL is carried by the schema and stays distinct from `""`. Values keep their text rendering (integers and reals in decimal, blobs as lowercase hex); typed members are the intended additive extension. `columns`, `truncated` and `limit` are unchanged. A client that reads `row[column_name]` must read `row[i]` for the column's index and branch on the cell's member. In `daemon.capnp`, `QueryResponse.rows` is a new field (@5, `List(List(QueryCell))`), and the old @2 is retired as `retiredRows` (`retired_rows`), never emitted. The daemon now encodes the `query` success response with the schema's JSON codec. `wire_format_major` moves from 2 to 3, so a major-2 client fails the version handshake instead of misreading rows; `compat_min_schema_version` stays 0.6.0, because the major does the refusal. In the Go module, `wire.QueryResponse.Rows` is `[][]wire.QueryCell`, and `wire.QueryRow` is removed. The Go drift gate no longer skips `query`. A new gate, `task schema:daemon-fixture-codec`, round-trips every daemon protocol fixture through `daemon.capnp` with the reference capnp JSON codec. It found that the `sheaf_invalidate` fixture and the Go test mirror both omitted `prior_generation`, which the daemon sends; both now include it.
