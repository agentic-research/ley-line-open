Section: Security

- **A microVM run the guest init refuses now ends as a failure, never a success** (bead `ley-line-open-7164ec`). Before the workload started, init bailed out with `exit()`: PID 1 exiting panicked the guest kernel and libkrun reported exit status 0, so a run init refused (a `/tmp` that is not a directory, a mount target that is a link, a missing exec config, a channel list it could not set up) was recorded as `Succeeded` with an empty console. Init (new LLO libkrun patch `0015`) now prints the reason on the console ports the host reads, reports exit status 125 and ends the VM, so the run ends `Failed` with the status in its detail and the reason in its `GuestOutput`. A refusal made before `/sys` and `/dev` are mounted (a link at `/dev`) reaches the host as exit status 125 without its text.
